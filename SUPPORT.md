# Support

## Customer Support

For access, installation, reinstall, subscription, and configuration assistance, use the official bot:

**[@CrystalFlip_bot](https://t.me/CrystalFlip_bot)**

## Before Contacting Support

1. Confirm that you installed the application through the official bot.
2. Note the application version and operating system.
3. Restart the application and check whether the issue persists.
4. Prepare reproducible steps and sanitized screenshots.
5. Remove API keys, wallet details, and other private information from logs.
