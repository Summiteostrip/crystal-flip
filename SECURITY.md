# Security Policy

## Official Distribution

Crystal Flip is distributed exclusively through the official control panel: [@CrystalFlip_bot](https://t.me/CrystalFlip_bot). Do not install packages, updates, or configuration files supplied by unofficial accounts or repositories.

Official project channel: [@Crystal_Flip](https://t.me/Crystal_Flip).

## Reporting a Vulnerability

Report suspected security issues privately through the official bot. Include:

- affected product and version;
- operating system;
- reproduction steps;
- expected and actual behavior;
- screenshots or logs with secrets removed.

Do not publish exploitable details before the maintainers have had an opportunity to investigate. Do not include private keys, seed phrases, session tokens, payment details, or customer information.

## Safe Configuration

- Never place private keys or API secrets in issue reports or public screenshots.
- Keep automatic opening disabled until filters have been reviewed.
- Use downloaded settings only when their source is trusted.
- Verify Telegram usernames carefully; impersonators may use similar names.
- Keep the operating system and application updated.

## Scope

This repository contains product documentation and media only. It does not contain application source code or production infrastructure.
