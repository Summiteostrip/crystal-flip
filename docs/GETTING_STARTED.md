# Getting Started

## 1. Use Official Access Channels

Start with the official control panel: [@CrystalFlip_bot](https://t.me/CrystalFlip_bot). Use only download and reinstall instructions supplied through the official bot.

Project announcements are published at [@Crystal_Flip](https://t.me/Crystal_Flip).

## 2. Activate Access

Choose a trial or subscription in the bot and follow its delivery instructions. Trial duration and prices may change; confirm the current terms in the bot before payment.

## 3. Install and Import Settings

Install the desktop application using the official package. If you have an exported Crystal Flip configuration, use the **IMPORT** option in settings.

If the bot supplies a default configuration, treat it as a starting point rather than a universally optimal strategy.

## 4. Configure Detection Sources

Enable only the networks, venues, and modules you intend to monitor. Starting with fewer sources makes initial filtering and troubleshooting easier.

## 5. Establish Conservative Filters

Consider beginning with:

- a meaningful minimum migration threshold;
- a maximum dev-buy;
- minimum social-account or Community-admin followers;
- a minimum AI Score if used;
- duplicate suppression;
- blacklists for known unwanted sources.

Keep automatic opening disabled until you have verified that the resulting detections match your expectations.

## 6. Add Trusted Entities

Populate wallet, Twitter account, Community admin, and keyword lists deliberately. A whitelist controls discovery priority; it should not be treated as proof that a launch is safe.

## 7. Review Before Automating

For each detection, inspect:

- previous launches and market-cap history;
- developer buying and selling behavior;
- Global Fees Paid and liquidity signals;
- attached tweet or Community context;
- score breakdown and risk warnings;
- current chart and independent market information.

## 8. Refine Using Detection History

Use notes, detection history, and hypothetical performance review to identify noisy filters. Adjust one variable at a time so that changes remain understandable.
